# AIG (American International Group, Inc.)

> Global insurance organization founded in 1919, operating in over 200 countries and jurisdictions.
> AIG writes commercial and personal property casualty, cyber, casualty, financial lines,
> professional liability, specialty risk and reinsurance. AIG has NO public developer program:
> there is no published OpenAPI, no public API reference, no SDK and no self-service signup.
> A production API gateway does exist and is credential-gated.

Generated by the API Evangelist enrichment pipeline from AIG's public surface on 2026-08-30.
Nothing below is inferred: every URL was fetched and its status recorded.

## What an integrator actually gets

- AIG's API gateway is https://commercial.api.aig.com — live, Okta-protected, undocumented.
  An unauthenticated call returns HTTP 400
  `{"error": "Protect Proxy via okta Service Policy: The message does not contain the Authorization header"}`.
- Tokens come from AIG's Okta identity host, https://auth1.customerpltfm.aig.com, which DOES serve
  anonymous OpenID Connect and RFC 8414 discovery documents.
- Access is provisioned through broker/producer/distribution relationships, not a developer portal.
- AIG's developer portal host, https://www.developers.aig.com, is still indexed by search engines
  (an API catalog with a Direct Quote API and a Product Configuration API) but refused TCP
  connections on both 443 and 80 when probed on 2026-08-30.
